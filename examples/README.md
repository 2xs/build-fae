# Examples

`examples/` contains small, focused examples that exercise one aspect of the tooling or file contract at a time.

Current examples:

- [`minimal_c/`](minimal_c): minimal C payload ELF that exports `start`
- [`minimal_rust/`](minimal_rust): minimal Rust payload ELF that exports `start`
- [`minimal_startup_asm/`](minimal_startup_asm): startup-only assembly example for `--startup-code`
- [`rust-fae-helloworld/`](rust-fae-helloworld): Rust application flow built from the SDK template stack
